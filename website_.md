# Portfolio Website for Agnik Roy

This document outlines the features and technologies used to build the portfolio website for Agnik Roy.

## Features

- **Single-Page Layout:** A modern, single-page design for a seamless user experience.
- **Responsive Design:** The website is fully responsive and works on all devices, including desktops, tablets, and mobile phones.
- **Smooth Scrolling:** Navigation links smoothly scroll to the corresponding sections of the page.
- **Hero Section:** A prominent hero section with a profile picture, name, and tagline.
- **About Me Section:** A section detailing education and technical skills.
- **Projects Section:** A grid of project cards showcasing 10 portfolio projects with descriptions.
- **Contact Section:** A section with an email address and a link to the LinkedIn profile.
- **Modern Aesthetics:** A dark theme with cyan accents, built with modern design principles in mind.

## Technologies Used

- **HTML5:** The standard markup language for creating web pages.
- **CSS3:** Used for styling the website. Custom styles are minimal, as most styling is handled by Tailwind CSS.
- **Tailwind CSS:** A utility-first CSS framework for rapidly building custom designs. The CDN version is used for simplicity.
- **JavaScript:** Used for implementing smooth scrolling functionality.

## How to Run Locally

1.  Clone or download the `agnik-roy-portfolio` directory.
2.  Open the `index.html` file in your web browser.

That's it! There are no complex build steps or dependencies to install since it's a static website and uses a CDN for Tailwind CSS.
